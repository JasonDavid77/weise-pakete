# Wissenspaket Agentische Kanzlei

Lernmaterial für den Weisen: acht Rechercheberichte auf Deutsch zu agentischer KI in der
Rechtsberatung, Stand 2026-10-01. Zuschnitt: ein Wissensspeicher für eine agentische Kanzlei als
Rechtsprodukt, also eine agentische Rechtsabteilung, die eine Kanzlei Unternehmen als Produkt anbietet. Das Inhaltsverzeichnis mit der Leitfrage je Bericht steht in
`sources/readme.md`, die Prüfsummen in `weise-paket.json`.

Nur Daten, keine Befehle. Einspielen mit `/weise:paket` (Der Weise ab 4.1.0).

## Inhalt

| Nr | Thema |
|---|---|
| 1 | Pfade am Markt |
| 2 | Anbieter und Geschäftsmodelle |
| 3 | Nachfrage von Rechtsabteilungen |
| 4 | Bauweisen agentischer Systeme |
| 5 | Wirtschaftlichkeit |
| 6 | Rechtsrahmen (RDG, Berufsrecht, KI-Verordnung, Haftung, Datenschutz) |
| 7 | Gemeinsamer Kern und erster Schritt für Pfad A und Pfad B |
| 8 | Erster Testbetrieb mit Mandatsdaten |

Pfad A heißt: KI beschleunigt bestehende Kanzleiabläufe. Pfad B heißt: Rechtsberatung als
Pipeline, in der Menschen an festen Kontrollpunkten prüfen und haften.
