# Wissenspaket weise-agentische-kanzlei: Inhaltsverzeichnis

Paket 1.0.0, Stand des Materials 2026-10-01. Acht Rechercheberichte auf Deutsch, erstellt mit
KI-gestützter Webrecherche (Claude mit Websuche, Quellen abgerufen am 01.10.2026). Jeder Bericht
hat eine Kurzfassung, Befunde mit Quellen, Gegenbelege und offene Punkte sowie eine Quellenliste.
Wie Belege, Einschätzungen und Anbieterangaben gekennzeichnet sind, steht in jedem Bericht.

Zuschnitt: ein Wissensspeicher für eine agentische Kanzlei als Rechtsprodukt, also für Kanzleien,
die Unternehmen eine agentische Rechtsabteilung als Produkt anbieten wollen.
Zwei Begriffe kehren wieder: **Pfad A** = KI beschleunigt bestehende Kanzleiabläufe je Anwendungsfall.
**Pfad B** = die Rechtsberatung als Pipeline, in der Menschen an festen Kontrollpunkten prüfen und
haften.
